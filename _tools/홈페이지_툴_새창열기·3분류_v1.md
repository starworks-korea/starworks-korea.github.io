## 2. 바꿀 내용
### 2.1 CAD 뷰어 = 새 창
- 아래 창에 뷰어를 바로 띄우지 않음
- 아래 창에는 여는 화면
  - 큰 버튼: 새 창에서 크게 열기
  - 작은 버튼: 이 화면에서 열기 (예전 방식, 남겨 둠)
  - 지원 형식 한 줄
- 위 프로그램 줄의 [CAD 뷰어] 버튼
  - 누르면 바로 새 창
  - 버튼에 ↗ 표시
- 새 창 = 브라우저 새 탭 (뷰어만 화면 전체)
- 페이지를 열자마자 자동으로 새 창을 띄우지는 않음
  - 브라우저가 팝업으로 막음 → 반드시 누를 때 열림

### 2.2 분류 3개
| 분류 | 프로그램 | 여는 방식 |
|---|---|---|
| CAD | CAD 뷰어 (2D·3D) | 새 창 |
| 시편 주문 | 시편 설계·견적 | 아래 창 (그대로) |
| CAM | 조각기 CAM | 아래 창 (그대로) |

- 시편 주문·CAM은 오른쪽 [새 창으로 열기] 버튼 그대로

### 2.3 주소
- `tools.html#viewer` · `#coupon` · `#cam` 그대로
- 옛 `#dxf` · `#cad3d` → `#viewer` 그대로
