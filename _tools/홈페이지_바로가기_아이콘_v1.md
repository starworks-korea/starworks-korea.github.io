# 홈페이지 바로가기 아이콘 (v1)

- 작성: 2026-11-27 18:15
- 지시 (대표, 2026-11-27 18:07)
  - 홈페이지를 바탕화면 바로가기로 만들면 크롬 모양으로 나옴
  - 스타웍스 로고가 보이게

## 1. 지금 상태
- 아이콘 설정 1줄뿐: `images/logo.svg`
  - 흰 글씨·투명 바탕 → 밝은 탭에서 안 보임
  - 가로로 긴 모양(517×205) → 정사각 아이콘에 안 맞음
- PNG 아이콘 없음, `favicon.ico` 없음, 사이트 매니페스트 없음
  - 크롬이 바로가기를 만들 때 쓸 그림이 없음 → 기본 모양

## 2. 조사
- 크롬(128부터) 메뉴: ⋮ › 전송, 저장, 공유
  - [바로가기 만들기]: 바탕화면에 바로가기, 새 탭으로 열림
  - [페이지를 앱으로 설치]: 바탕화면 + 시작 메뉴, 따로 창으로 열림
  - 둘 다 사이트의 매니페스트 아이콘 → 없으면 파비콘을 씀
  - 출처: developer.chrome.com 「How Chrome helps users install the apps they value」, support.google.com/chrome/answer/15085120
- 주소창의 주소를 바탕화면으로 끌어다 놓아 만든 바로가기(.url)
  - 윈도우가 기본 브라우저 모양을 붙임
  - 사이트 쪽 설정으로는 바꿀 수 없음 → 위 메뉴로 만들어야 함

## 3. 만들 것
### 3.1 아이콘 그림 (원본 = `images/logo.svg`의 별 마크·글자 그대로)
| 종류 | 모양 | 크기 | 쓰는 곳 |
|---|---|---|---|
| 작은 것 | 군청 바탕 + 별 마크 | 16 · 32 · 48 · 64, SVG | 브라우저 탭, 작은 바로가기 |
| 큰 것 | 군청 바탕 + 별 마크 + STAR Works | 96 · 128 · 192 · 256 · 512 | 바탕화면, 시작 메뉴, 휴대폰 홈 화면 |
| 안드로이드용 | 큰 것, 여백 넓힘(가장자리 잘림 대비) | 192 · 512 | 안드로이드 홈 화면 |
| 아이폰용 | 큰 것, 모서리 각짐 | 180 | 아이폰 홈 화면 |

- 색: 군청 `#1E3252` 바탕, 흰색 로고 (회사 브랜드 그대로)
- 위치: `images/icons/`, `favicon.ico`(루트)

### 3.2 매니페스트 2개
- `manifest.webmanifest` (영어): 이름 STAR Works, 시작 `/`
- `ko/manifest.webmanifest` (한국어): 이름 스타웍스, 시작 `/ko/`
- 화면 방식 `minimal-ui`: 설치하면 따로 창 + 뒤로·새로 고침 단추
- CAD 뷰어(`tools/`)는 자기 매니페스트 그대로 (따로 설치되는 앱)

### 3.3 모든 페이지 머리글
- 아이콘·매니페스트·테마 색 줄을 공통 코드 한 곳(`i18n.icon_links`)에서 만듦
- 적용: 회사소개·프로젝트·연락처(`make_static.py`), 플레이리스트·툴(`page_shell.py`), 시편 설계(`make_tools.py`)
- 그 밖의 페이지(조각기 CAM, 게임, 이동 페이지)는 루트 `favicon.ico`로 표시됨

## 4. 검사 항목
- 아이콘 파일 크기·투명도, `favicon.ico` 안의 크기 3개
- 매니페스트: 형식, 아이콘 주소가 실제로 열리는지
- 크롬의 설치 가능 판정(매니페스트 오류 0)
- 모든 페이지에 아이콘 줄이 1번씩만 들어갔는지, 생성 코드를 두 번 돌려도 같은지
- 실제 사이트에서 아이콘·매니페스트 응답 확인
